# API-TAQUERIA
La API de Taquería permite gestionar de manera eficiente un negocio de venta de tacos, proporcionando funcionalidades clave como el manejo de menús, pedidos, clientes y pagos. Diseñada para integrarse fácilmente con aplicaciones móviles y sitios web, esta API facilita la automatización y administración de una taquería digital.
